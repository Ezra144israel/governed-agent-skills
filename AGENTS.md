# governed-agent-skills — Repository Rules

This file governs the repository for all agents.

Standing environment skills (`governed-operator`, `reasoning-doctrine`,
`cil-grounding`) load once at session start and remain active; do not copy or
redefine them here.

## Repository rules

- TEAM HUB MEMORY (light): at the start of substantive work in this repo, read
  `memory/01-latest-handoff.md`; treat it as continuity, not authority — verify
  load-bearing claims against the repo (LSN-018). Before ending substantive
  work: rotate the current record into `memory/archive/<date>-handoff.md` and
  write the new latest (light profile: current state; decisions with why; next
  actions + the one after; files & surfaces; constraints; verification
  performed; date + session identity). A session that changed nothing states so
  instead of rewriting. Project continuity stays here — it never enters CIL.
- Make the smallest safe change inside the authorized seam; do not widen scope
  or modify unrelated files.
