Governed Agent Skills

Six skills that give AI coding agents a working method, a constitution, and hard limits on self-approval.

// the agent that builds a thing never approves it

The loop

A seat is a role for one session, not a person and not a vendor. Any model can fill any seat. What can never happen: the session that built the thing approving the thing.

When each skill loads

Any real task begins→reasoning-doctrine Stops drift. Frame, ground, converge, execute, verify. Every task.
Work touches a repo, a record, or another agent→governed-operator The constitution. Seats, gates, and one rule above all: the builder never approves its own work.
Outcome, scope, authority, evidence are fixed→write-maintainable-code The smallest change that truly does the job. Nothing speculative survives.
The work needs a plan→portable-adaptive-planning A plan is not permission. FINAL, then GO, and nothing runs without both.
Tests are written or judged→test-verification Tests prove behavior, not internals. Green is not proof.
You explicitly ask for maximum assurance→ship-it-or-fix-it On your say-so only. The acceptance oracle freezes before the code exists.

The governance dial

G0

Ordinary answers and analysis. Proportional self-checks, no ceremony.

G1

Real changes. One builder, one independent reviewer, publication stays with you. The default.

G2

Ship It or Fix It. Frozen oracle, independent judges, a cold final check. Only when you say so.
