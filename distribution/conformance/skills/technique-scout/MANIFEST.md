# MANIFEST — technique-scout v15

Every member of this package **other than this file**, with its content digest. The member
set is `SKILL.md`, `MANIFEST.md`, and everything under `references/`. Dated backups matching
`*.pre-*` are not members, are never propagated, and are not evidence of a mixed package —
`skillsync`'s `companion_files()` applies the same exclusion. Verify each
member against this list as you load it. This file carries no digest for itself — computing
one would change it — which is the limit spelled out two paragraphs below, and which
`SKILL.md` states the same way. A digest that does not match, or a member absent from the
installation, means
the loaded package is mixed — the run is `PARTIAL` and may not record a complete result.
Frontmatter alone cannot detect that: a stale reference alongside a current `SKILL.md` still
self-reports version 15.

**What this manifest can and cannot do.** It detects *accidental* mixing — a partial update
that left one stale file behind, the realistic and common failure. It cannot detect
*deliberate* tampering, because it does not verify itself: anyone able to rewrite a member
can rewrite this list to match. Closing that requires a trust anchor from outside the package
— a loader or installer receipt carrying this file's expected digest, or a content-addressed
package whose root digest is supplied independently. Neither exists here, and a prose
artifact cannot manufacture one.

So treat a clean manifest check as evidence the install is internally consistent, not as
proof it is authentic. Stating the weaker claim is the point; an earlier version implied the
stronger one.

**Cite `PACKAGE_DIGEST`, not `VERSION`.** The digest is computed from the member rows by
`skillsync` and is regenerated whenever they change, so it cannot describe a package it is
not. `VERSION` is typed by a person, is a human label, and **is not evidence**: it went
stale once already, on 2026-08-20, and a run that cited it would have named a package that
no longer existed. A report's package identity is the digest. The `AMENDED` lines below say
why the digest moved, which is the one thing a generator cannot work out for itself.
